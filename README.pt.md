# 🌍 Global Translate

**Global Translate** permite que você se comunique facilmente entre idiomas e culturas com traduções rápidas e precisas na palma da sua mão.

![Demonstração de tradução global](https://github.com/KrishBharadwaj5678/Global-Translate/raw/main/GlobalTranslateDemo.png)

## ✨ Funcionalidades

| Funcionalidade                   | Descrição                                                 |
| -------------------------------- | --------------------------------------------------------- |
| 🌐 Suporte a vários idiomas      | Traduza entre mais de 30 idiomas com facilidade           |
| 🔁 Dois mecanismos de tradução   | Usa `googletrans` e `deep-translator` para maior precisão |
| 💬 Tradução de texto             | Traduza qualquer texto instantaneamente com um clique     |
| 📋 Copiar com um clique          | Copie o texto traduzido facilmente                        |
| 🖥️ Interface amigável           | Interface moderna e responsiva feita com Streamlit        |
| 🌙 Modo escuro                   | Conforto visual em qualquer ambiente                      |
| 📱 Compatível com mobile         | Funciona perfeitamente em celulares e tablets             |
| 🔒 Privacidade em primeiro lugar | Nenhum dado do usuário é armazenado ou rastreado          |

---

## 🛠️ Tecnologias Utilizadas

| Tecnologia         | Descrição                               |
| ------------------ | --------------------------------------- |
| 🐍 Pitão          | Linguagem principal do projeto          |
| 📦 Streamlit       | Framework para interface web interativa |
| 🌍 Googletrans     | API do Google Tradutor                  |
| 🌐 Tradutor Profundo | Motor de tradução multi-fonte           |

## 🚀 Como Começar

### 1️⃣ Clonar o repositório

```bash
git clone https://github.com/KrishBharadwaj5678/Global-Translate.git
```

### 2️⃣ Entrar na pasta do projeto

```bash
cd Global-Translate
```

### 3️⃣ Instalar dependências

```bash
pip install -r requirements.txt
```

### 4️⃣ Executar o app

```bash
streamlit run app.py
```
