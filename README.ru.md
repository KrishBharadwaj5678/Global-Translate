# 🌍 Глобальный Translate

**Глобальный Translate** это быстрый и точный инструмент перевода, который помогает легко общаться между языками и культурами.

![ГлобальныйTranslateДемо](https://github.com/KrishBharadwaj5678/Global-Translate/raw/main/GlobalTranslateDemo.png)

## ✨ Возможности

| Функция                          | Описание                                                          |
| -------------------------------- | ----------------------------------------------------------------- |
| 🌐 Поддержка множества языков    | Перевод более чем на 30 языков                                    |
| 🔁 Два движка перевода           | Использует `googletrans` и `deep-translator` для большей точности |
| 💬 Перевод текста                | Мгновенный перевод любого текста одним кликом                     |
| 📋 Копирование в один клик       | Лёгкое копирование переведённого текста                           |
| 🖥️ Удобный интерфейс            | Простой и современный интерфейс на Streamlit                      |
| 🌙 Тёмная тема                   | Комфортное использование в любое время суток                      |
| 📱 Поддержка мобильных устройств | Корректно работает на телефонах и планшетах                       |
| 🔒 Конфиденциальность            | Данные пользователей не сохраняются и не отслеживаются            |

## 🚀 Начало работы

### 1️⃣ Клонируйте репозиторий

```bash
git clone https://github.com/KrishBharadwaj5678/Global-Translate.git
```

### 2️⃣ Перейдите в папку проекта

```bash
cd Global-Translate
```

### 3️⃣ Установите зависимости

```bash
pip install -r requirements.txt
```

### 4️⃣ Запустите приложение

```bash
streamlit run app.py
```
