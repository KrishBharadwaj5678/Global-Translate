# 🌍 グローバル Translate

**グローバル Translate** は、言語や文化の壁を越えてスムーズにコミュニケーションできるようにする、高速かつ高精度な翻訳ツールです。

![グローバルTranslateデモ](https://github.com/KrishBharadwaj5678/Global-Translate/raw/main/GlobalTranslateDemo.png)

## ✨ 機能

| 機能           | 説明                                          |
| ------------ | ------------------------------------------- |
| 🌐 多言語対応     | 30以上の言語間で簡単に翻訳可能                            |
| 🔁 複数翻訳エンジン  | `googletrans` と `deep-translator` を使用し精度を向上 |
| 💬 テキスト翻訳    | 任意のテキストをワンクリックで即座に翻訳                        |
| 📋 ワンクリックコピー | 翻訳結果を簡単にクリップボードへコピー                         |
| 🖥️ 使いやすいUI  | Streamlitで構築されたシンプルでモダンなUI                  |
| 🌙 ダークモード対応  | どんな環境でも見やすい表示                               |
| 📱 モバイル対応    | スマホやタブレットでも快適に利用可能                          |
| 🔒 プライバシー重視  | ユーザーデータは保存・追跡されません                          |

---

## 🛠️ 技術スタック

| 技術                 | 説明                     |
| ------------------ | ---------------------- |
| 🐍 パイソン          | コアプログラミング言語            |
| 📦 Streamlit       | インタラクティブなWeb UIフレームワーク |
| 🌍 Googletrans     | Google翻訳API            |
| 🌐 ディープトランスレーター | 複数ソース対応の翻訳バックエンド       |

## 🚀 はじめ方

### 1️⃣ リポジトリをクローン

```bash
git clone https://github.com/KrishBharadwaj5678/Global-Translate.git
```

### 2️⃣ フォルダへ移動

```bash
cd Global-Translate
```

### 3️⃣ 依存関係をインストール

```bash
pip install -r requirements.txt
```

### 4️⃣ アプリを実行

```bash
streamlit run app.py
```
